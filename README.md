# Networkwalks-Internship-Week-1
# 🔐 Cybersecurity Lab Setup Using VirtualBox and Kali Linux

## 📌 Project Overview

This project documents the setup and configuration of a virtual cybersecurity lab using Oracle VirtualBox and Kali Linux.

The lab environment demonstrates fundamental virtualization and networking concepts, including NAT network configuration, static IP assignment, network troubleshooting, DNS resolution, and virtual machine snapshot management.

I am documenting this work as part of my cybersecurity internship requirements. These concepts are already familiar to me, and this project serves as practical documentation of my existing knowledge and configuration process.

## 🎯 Objectives

* Set up a virtual lab environment using VirtualBox.
* Configure a private NAT network.
* Assign a static IP address to Kali Linux.
* Enable shared folders and clipboard integration.
* Troubleshoot network connectivity issues.
* Verify internet connectivity and DNS resolution.
* Create a virtual machine snapshot for recovery.

## 🛠️ Tools and Technologies

* **Oracle VirtualBox** — Virtualization platform
* **Kali Linux** — Linux distribution for cybersecurity learning and testing
* **NAT Networking** — Network connectivity configuration
* **Linux Networking Tools** — Connectivity and network troubleshooting

## ⚙️ Tasks Completed

### 1. Virtual Machine Setup

Installed and configured Kali Linux inside VirtualBox.

### 2. NAT Network Configuration

Created and configured a virtual network to provide network connectivity to the lab environment.

### 3. Static IP Configuration

Configured a static IP address for Kali Linux to support consistent network settings.

### 4. Shared Folders and Clipboard

Enabled shared folders and clipboard integration between the host system and the virtual machine.

### 5. Network Troubleshooting

Identified and resolved a connectivity issue caused by a subnet mismatch.

### 6. Connectivity and DNS Verification

Tested internet connectivity and verified DNS resolution to confirm that network communication was working correctly.

### 7. Virtual Machine Snapshot

Created a clean VM snapshot to provide a recovery point before future lab activities.
